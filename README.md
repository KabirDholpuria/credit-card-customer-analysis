# Credit Card Customer Analysis Dashboard

## Project Overview
Built an interactive Excel dashboard to analyze credit card customer data.

## Analysis Performed
- Customer demographics analysis
- Income group analysis
- Age group segmentation
- Card category distribution
- Existing vs attrited customer comparison

## Key Insights
- Majority customers belong to mature adult segment
- Blue card category dominates customer base
- Existing customers significantly outnumber attrited customers
- Most customers belong to low and middle income groups

## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Charts
- Data Visualization
